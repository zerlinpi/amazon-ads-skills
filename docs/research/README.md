# Research notes

Dated notes in this directory record source review and adoption reasoning. They are evidence/provenance, not automatically active decision policy. Normative behavior must be independently rewritten into `skills/`, `references/`, `schemas/`, `playbooks/` and covered by tests/evals.

Source priority: Amazon official/current documentation → relevant specifications → license-clear open source with real engineering evidence → practitioner/community evidence. Community posts can expose recurring operational failure modes, but anecdotes and fixed percentages are not repository defaults.
