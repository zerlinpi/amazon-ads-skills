# Documentation

Use the narrowest layer that answers the question.

## Users

- `GETTING-STARTED.md` — install, validate and first run.
- `CAPABILITIES.md` — what the repository can do and which Skill owns each decision.
- `PLATFORM-INTEGRATION.md` — integrate the Skill library into a custom agent/advertising platform.

## Maintainers and integrators

- `ARCHITECTURE.md` — progressive loading, connector gates, evidence lineage, memory, experiments and evaluation.
- `SOURCES.md` — source provenance, licenses and adoption/rejection boundaries.
- `research/` — dated research notes; research evidence is not automatically normative policy.

## Historical material

- `archive/` — superseded plans/specs kept for provenance only. Archived documents are not current instructions.

Decision logic lives in `skills/`, shared contracts in `references/` and `schemas/`, recurring workflows in `playbooks/`, and regression/effectiveness material in `evals/`.
